## Bug yang ditemukan saat verifikasi

- `x-ui.confirm-dialog` membuat nama modal acak (UUID) tiap render. Dialog Flux memakai `wire:ignore.self`, jadi setelah komponen Livewire re-render (mis. ubah qty), tombol "Hapus Semua" dan hapus item tidak membuka modal. Nama kini deterministik (md5 judul + deskripsi, atau `name` eksplisit).
- File `errors/4xx`/`5xx` saja tidak dipakai Laravel karena view bawaan per kode (404, 403, ...) lebih dulu cocok; ditambahkan file per kode.
